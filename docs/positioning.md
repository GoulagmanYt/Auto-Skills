# Project scope

Auto-Skills maintains explainable, pinned guidance for Codex users working across repositories or mixed-technology workspaces.

| Property | Acceptance example |
| --- | --- |
| Automatic preparation | A wrapped first visit creates the lock; an unchanged return does no selection or installation. |
| Workspace isolation | A Rust task excludes React specialties; changing React preserves backend artifacts. |
| Eligibility before ranking | Known incompatible versions or missing required tools are rejected before candidate scoring. |
| Reversible ownership | Uninstall preserves unrelated edits and stops on ambiguous generated-file conflicts. |
| Explicit uncertainty | Unknown repositories receive portable guidance and visible classification/coverage gaps. |

The value established by these contracts is explainable context management. Skill counts, repository popularity and startup token estimates do not establish whole-session savings or conflict-free model behavior.
