# Community conduct

Treat contributors respectfully. Discuss observable behavior and evidence, welcome corrections, and keep criticism about the work. Harassment, threats, discriminatory abuse, doxxing and publishing another person's private information are unacceptable.

Maintainers may edit or remove harmful content and restrict participation. Report incidents privately through an available maintainer contact; if none is listed, request a private channel without posting identifying details. Maintainers involved in a report should not adjudicate it.
